# VIN Decoder

A simple web-based VIN (Vehicle Identification Number) decoder that allows users to enter a VIN and retrieve vehicle details using the NHTSA API.

**Live Demo**: [VIN Decoder](https://okonma01.github.io/vin-decoder/)

## Features
- User inputs a VIN via a prompt
- Validates VIN format before making API request
- Fetches vehicle details (Year, Make, Model) using the NHTSA API
- Displays results in an alert box
- Option to reload the page after decoding
- Simple and responsive UI with a car-themed background

## Technologies Used
- HTML, CSS, and JavaScript
- NHTSA API for VIN decoding
- Flaticon icons for the background (credits below)

## Setup & Usage
1. Open the `index.html` file in a browser.
2. Enter a valid 17-character VIN when prompted.
3. View the decoded vehicle details in an alert box.
4. Choose to reload the page if needed.
